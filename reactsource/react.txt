리액트 컴파일러
-> 부모가 렌더링 시 관련없어도 자식 렌더링 같이 됨 => 관련 없으면 렌더링 안되도록 해줌
-> useMemo() : 계산 결과 기억, 판단 후 적절하다고 판단이 되면 이 부분도 해결해줌
-> useCallback() : 함수 기억 (부모가 자식에게 함수를 props로 넘길때)
리렌더링 시 함수는 새롭게 생성됨

useId() : 각 컴포넌트 인스턴스 마다 고유한 ID 를 제공
            언마운트 되기 전까지 동일한 ID 유지

useContext(): 상태를 여러 컴포넌트에 어떻게 공유할지 관리

3. 상태를 공유할 자식 컴포넌트를 Provider로 감싸기
4. 자식 컴포넌트에서 공유된 값 사용
